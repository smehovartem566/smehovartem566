### Messenger + Photo Editor

**Android-приложение:** общий чат и редактор фото.

- **Фичи:**  
  - Общий чат с регистрацией (до 5 аккаунтов на устройстве) 
  - Редактор фото: обрезка, поворот, рисование, добавление текста 
  - Кастомные реакции и стикеры из фото (пользователь может превратить своё фото в стикер) 
  - Ответ на сообщение свайпом, редактирование и удаление сообщений  
  - Аватарка пользователя

- **Технологии:**  
  - Java, Android Studio  
  - Firebase Realtime Database (хранение сообщений и стикеров)  
  - Base64 (кодирование изображений для хранения в Firebase)  

- **Особенность:**  
  Изображения передаются и хранятся в виде текста через Base64 — это был эксперимент, но он работает.

> Проект для личного интереса, код не выложен. Но опыт позволяет мне проектировать API и веб-сервисы с учётом потребностей мобильных клиентов.
